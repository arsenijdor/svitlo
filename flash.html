Прошити плату

Перетворює плату ESP8266 або ESP32 на датчик світла. Нічого встановлювати не треба — прошивка заливається прямо з браузера.

Цей браузер не вміє працювати з USB. Відкрийте сторінку в Chrome, Edge або Firefox на комп'ютері (на Android — у Chrome). Сторінку відкрито не по HTTPS — прошивка недоступна.

Плата має бути вже вставлена в USB. Браузер сам визначить чип і вибере потрібний файл.

Що буде далі

  1. Натиснути кнопку вище й вибрати порт плати (COM3, COM5…).
  2. Дочекатися «Готово» — це 20–40 секунд.
  3. Плата створить власну мережу Svitlo-XXXX.
  4. Підключитися до неї телефоном → відкриється сторінка налаштування.
  5. Вибрати свій Wi-Fi 2.4 ГГц, вписати пароль, зберегти.
  6. Скопіювати топік, який покаже плата, у застосунок.

Якщо щось не так

Кнопка сіра / «браузер не підтримується» Відкрийте в Chrome або Edge. Safari й Firefox на macOS старіших версій Web Serial не мають.
Плата не з'являється в списку портів Замініть кабель на той, що передає дані (зарядні не підходять). На Windows для дешевих плат іноді потрібен драйвер CH340.
«Failed to connect» Від'єднайте й приєднайте плату, спробуйте ще раз. Не тримайте затиснутою кнопку reset.
Не бачить мережу 2.4 ГГц ESP8266 фізично не бачить 5 ГГц. Якщо роутер роздає одну назву на обидва діапазони — зробіть окрему назву для 2.4 ГГц.

Перепрошити або скинути

Той самий файл можна заливати повторно — наприклад, після оновлення прошивки. Прошивка стирає збережені налаштування Wi-Fi, тому після неї плату треба налаштувати заново (або скористатися «Скинути налаштування» на сторінці плати, якщо Wi-Fi просто змінився).

Прошивка: firmware/svitlo_portal у репозиторії. Повна інструкція зі складання — у README проєкту.
